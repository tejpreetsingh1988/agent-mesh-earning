Agent Mesh

Earnings briefings, verified before they’re written. Four agents do the work in order, each accountable for its own step — watch their cards fill in below as each one finishes.

Search runs on Cloudflare AI Search over the company directory — pick a match and its briefing runs. Typing a ticker works too, since each company page carries its ticker. Only one search per click, so the free query pool is never burned by typing.
